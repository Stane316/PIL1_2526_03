1. MEDIA (upload photos de profil)
   - Ajouter dans settings.py :
       MEDIA_URL = '/media/'
       MEDIA_ROOT = BASE_DIR / 'media'
   - Ajouter dans config/urls.py (dev uniquement) :
       from django.conf import settings
       from django.conf.urls.static import static
       urlpatterns += static(settings.MEDIA_URL, document_root=settings.MEDIA_ROOT)
   - Dans accounts/models.py, le champ photo_profil utilisera :
       photo_profil = models.ImageField(upload_to='profile_pictures/', null=True, blank=True)

2. WEBSOCKET (messagerie temps réel)
   - Installer : pip install channels daphne channels-redis
   - Configurer CHANNEL_LAYERS dans settings.py avec Redis
   - Le fichier asgi.py doit inclure le routage Channels

3. PACKAGES REQUIS (requirements.txt)

   djangorestframework
   djangorestframework-simplejwt
   django-cors-headers
   channels
   daphne
   channels-redis
