gi# IFRI MentorLink

## Description

IFRI MentorLink est une plateforme de mentorat académique et
professionnel destinée aux étudiants de l'IFRI.

Elle permet aux étudiants de rechercher de l'aide dans certaines
matières ou compétences, de proposer leur aide à d'autres étudiants et
d'échanger via une messagerie intégrée.

## Objectifs

-   Faciliter l'entraide entre étudiants
-   Mettre en relation mentors et mentorés
-   Favoriser le partage de compétences
-   Centraliser les échanges académiques
